# MaxStriX324 KiCad Component Library

Public version-controlled KiCad component library: **schematic symbols, PCB footprints, and 3D models**.

## Components

| Part | Symbol | Footprint | 3D |
|---|---|---|---|
| Texas Instruments UCC21750, wide SOIC-16 (DW) | `MaxStriX324:UCC21750` | `MaxStriX324:UCC21750_SOIC16W_P1.27mm` | Generated approximate STEP |
| RUICHI EC3503, 16-pin THT transformer bobbin | `MaxStriX324:EC3503_Flyback_4CT_16P_DRAFT` (application-specific) | `MaxStriX324:EC3503_16P_THT` | Generated approximate STEP + WRL |

The transformer footprint now labels winding starts, center taps and ends, with start dots on both the footprint and symbol. These are **provisional** assignments and not a safe, manufacturer-approved pinout. The [EC3503 transformer symbol pinout and isolation warning](docs/EC3503_flyback_4CT_16P.md) must be read before using the draft symbol. The EC3503 footprint contains **16 pins with provisional numbering**. It is **not** a ready-made transformer winding schematic.

## One-click installation on Windows (KiCad 8 / 9 / 10)

You do **not** need to manually copy symbols, footprints or 3D models into KiCad, or register the libraries through the UI.

1. Install KiCad, launch it once, and initialize the **default KiCad symbol and footprint library tables**. Then close all KiCad windows.
2. **Download [setup.bat](https://raw.githubusercontent.com/MaxStriX324/kicad-component-library/main/setup.bat)** (use **Save link as...** in your browser) and run it. It works without administrator rights.
3. Start KiCad again and find the **MaxStriX324** library in the symbol and footprint browsers.

If KiCad is running when you start the installer, it will ask you to **save and close KiCad**, then **press Enter in the same installer window**. It does not terminate KiCad automatically or lose unsaved edits. Typing `Q` cancels safely.

The installer retrieves the public source from GitHub and stores it in:

```text
%LOCALAPPDATA%\MaxStriX324\KiCadLibrary
```

If **Git for Windows** is available it uses a shallow `git clone`. Without Git it downloads and extracts a GitHub ZIP. Updates use `git pull --ff-only` when the installation is a Git checkout; otherwise they use a new ZIP with a backup of the previous version.

The installer registers the shared library **globally** using **absolute paths** to its symbol library and `.pretty` footprint folder, preserves default libraries, repairs old entries based on environment variables, and backs up the library tables before changing them. It also sets the Windows user environment variable `MAXSTRIX_KICAD_LIB` for **3D STEP paths**. If 3D models are missing immediately after first installation, sign out and sign in again so Windows desktop processes inherit the new user variable, or configure it in KiCad's **Preferences → Configure Paths**.

### Updating

Use the **external updater**, deliberately stored outside the library folder so ZIP installations can be replaced safely without locking any running batch file:

```text
%LOCALAPPDATA%\MaxStriX324\Update-MaxStriX324.bat
```

You can also [download the standalone updater](Update-MaxStriX324.bat) and run it from Downloads. It does not need Git. The installed library's `update.bat` simply opens the external updater in a new console window.

Or run your downloaded `setup.bat update`. If KiCad is open, the script asks you to close it and press Enter to continue.

### Checking

Run `check.bat` in the installed folder or use `setup.bat check`. The check verifies files and global table registration.

### Advanced installation from a clone

```powershell
git clone https://github.com/MaxStriX324/kicad-component-library.git
cd kicad-component-library
.\install.bat
```

This installs a **managed copy** to the same fixed location above instead of registering a transient Downloads directory. The `update.bat` script updates this managed copy; if it detects local Git modifications, it refuses to overwrite them. No administrator rights are required.

If KiCad has not been initialized yet, the installer will stop with an explanation rather than replace its stock library tables.

## Reproducible 3D models

The STEP models are generated by [CadQuery](https://cadquery.readthedocs.io/) from approximate mechanical envelopes, **not from official manufacturer CAD**. They are useful for preliminary 3D composition only.

To regenerate locally:

```powershell
python -m pip install cadquery
python scripts/generate_3d_models.py
```

The GitHub Actions workflow can also regenerate, validate the STEP files, and commit them to `main` when its generator changes.

## Hardware verification and safety

- EC3503: 2 × 8 pins, 5.00 mm pin pitch, 35.00 mm between rows, nominal outline 42.8 × 39.8 mm. Pad numbering is **not provided by the supplier** and must be physically verified before fabrication.
- UCC21750: double-check exact orderable package, pad geometry, pin functions, and land pattern against the current TI datasheet.
- Generated models have no verified ferrite core or winding geometry and do not demonstrate adequate creepage or clearance for high-voltage isolation.
- Always inspect KiCad ERC/DRC, 3D Viewer, the real component fit, and isolation distances before ordering boards.
